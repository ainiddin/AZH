# AZH — учёт шарфов Jacquemus

Десктоп-приложение для Windows: продажи, склад, закупки, расходы, окупаемость и отчёты Excel.
Данные хранятся в **приватном репозитории GitHub** и синхронизируются между всеми, кто работает с приложением.

---

## Как это работает

- **Просмотр** (серый индикатор) — режим по умолчанию. Данные обновляются с GitHub при запуске и каждые 60 секунд.
- **Активный режим** (зелёный) — кнопка **«Начать работу»**. Приложение берёт «замок» (`lock.json` в репозитории): пока он у вас, остальные могут только смотреть и видят «Сейчас работает {имя} с 14:32».
  - Замок продлевается каждые 2 минуты и действует 10 минут. Если приложение закрылось или упало, замок через 10 минут просрочится, и его можно будет забрать (с предупреждением).
  - Все правки сначала копятся в черновике на вашем компьютере. Он переживает падение: при следующем запуске приложение предложит сохранить черновик.
- **«Сохранить (push)»** — все изменения уходят на GitHub **одним коммитом**, например «Айниддин: +2 продажи, +1 расход».
- **«Сохранить и выйти»** — то же самое, плюс замок освобождается в этом же коммите.
- Если кто-то успел изменить данные или перехватил замок, сохранение отменяется: ничего не перезаписывается, вы увидите сообщение.
- Без интернета войти в активный режим нельзя. Просмотр работает с последней сохранённой копией.

Вкладка **«История»** — кто, когда и что изменил (список коммитов).

## 1. Создать репозиторий для данных

1. Откройте <https://github.com/new>.
2. Имя, например, `jacquemus-data`. Выберите **Private**.
3. Галочки «Add README» и прочие **не ставьте**: репозиторий должен быть пустым.
4. Нажмите **Create repository**.
5. Добавьте компаньонов: **Settings → Collaborators → Add people**.

При первом подключении приложение само создаст файлы:

```
data/purchases.json   data/sales.json   data/expenses.json   data/config.json   lock.json
```

и запишет начальную партию «Партия №1» (10 шарфов, 89 348,08 ₸, себестоимость 8 934,81 ₸/шт).

## 2. Создать токен (каждому пользователю — свой)

1. GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Token name**: `AZH`. **Expiration**: например, 1 год.
3. **Resource owner**: владелец репозитория. Если репозиторий чужой, владелец должен разрешить fine-grained токены, либо можно попросить его добавить вас в коллабораторы.
4. **Repository access** → **Only select repositories** → выберите `jacquemus-data`.
5. **Permissions → Repository permissions → Contents → Read and write**. Остальное не трогайте (Metadata: Read-only выставится сам).
6. **Generate token** и скопируйте `github_pat_…`.

Токен хранится на компьютере в зашифрованном виде (Windows DPAPI через Electron safeStorage), в открытом виде нигде не лежит.

## 3. Установить приложение

1. Запустите `AZH-Setup-1.0.0.exe`.
   - Windows может показать «Windows защитила ваш компьютер», потому что установщик не подписан. Нажмите **Подробнее → Выполнить в любом случае**.
2. При первом запуске введите:
   - **Ваше имя** — его увидят другие и в истории;
   - **Репозиторий** — `владелец/jacquemus-data`;
   - **Токен**.
3. Если репозиторий пуст, нажмите **«Создать и засеять данные»**. Это делает только первый пользователь, остальные сразу видят данные.

Настройки потом меняются во вкладке **«Настройки»**.

## Excel

- **«Отчёт Excel»** (в шапке) сохраняет книгу с листами: Сводка, Продажи, Склад, Закупки, Расходы, Каналы, По месяцам.
  В ней форматы ₸ и %, закреплённая шапка, автофильтр, итоги формулами. В листах Продажи, Закупки и Расходы есть скрытая колонка ID.
- **«Ввести данные из Excel»** работает только в активном режиме.
  - **«Скачать шаблон»** — пустая книга с теми же колонками, выпадающими списками и серыми строками-примерами.
  - Можно загрузить `.xlsx`, `.xls` или `.csv`. Листы ищутся по названию, колонки — по заголовкам (порядок не важен).
  - Перед записью показывается предпросмотр: что будет добавлено и обновлено, ошибки с указанием листа, строки и колонки, возможные дубли (по умолчанию не импортируются).
  - Строки **с ID** обновляют существующие записи, **без ID** создают новые. Схема «выгрузил отчёт → поправил в Excel → загрузил обратно» дублей не создаёт.
  - Закупки в Excel: одна партия = несколько строк с одинаковыми «Дата» и «Партия». Тип строки «Товар» (Цвет, Кол-во, Цена ¥) или «Затрата» (Статья, Сумма ₸).

## Для разработчика

Нужен Node.js 20+.

```bash
npm install
npm run dev        # запуск в режиме разработки
npm test           # unit-тесты (расчёты, синхронизация двух клиентов, Excel)
npm run typecheck
npm run dist       # сборка установщика → dist/AZH-Setup-<версия>.exe
```

Проверить двух пользователей на одном компьютере можно через отдельный профиль:

```powershell
$env:AZH_PROFILE="$env:TEMP\azh-user2"; npx electron .
```

### Структура

```
src/shared/     чистая логика без Electron — её покрывают тесты
  calc/         себестоимость, склад, финансы, безубыточность, сценарии, предупреждения
  sync/         SyncEngine (режимы, замок, push), RemoteStore, MemoryStore для тестов
  excel/        колонки, парсинг дат/чисел, план импорта (дубли, обновление по ID)
src/main/       Electron: GitHubStore (Octokit), токен (safeStorage), файлы, Excel (ExcelJS/SheetJS), IPC
src/preload/    мост window.api
src/renderer/   React + Tailwind: экраны
tests/          vitest
```

### Автообновление

Обновления ставятся через GitHub Releases **репозитория приложения** (не репозитория данных!).
Он указан в `electron-builder.yml` → `publish` (`ainiddin/AZH`).
Чтобы обновления скачивались без токена, этот репозиторий должен быть **публичным**. Данные лежат в другом, приватном репозитории.

Выпустить новую версию:

1. Поднять `version` в `package.json`.
2. `$env:GH_TOKEN="<токен с правом Contents: write на репозиторий приложения>"; npm run release`
3. На GitHub опубликовать созданный черновик релиза. У пользователей обновление скачается само и установится при выходе из приложения.
